# EnviroMonitor – Requirements Specification
## Version 1.0

### Project Overview
EnviroMonitor is a web-based environmental monitoring system designed to provide users with information about air quality and environmental conditions.

### Functional Requirements

1. The system shall allow users to view Air Quality Index (AQI) information.
2. The system shall display major air quality parameters.
3. The system shall allow users to search for a location.
4. The system shall display the AQI status of the selected location.
5. The system shall provide a simple and user-friendly interface.

### Non-Functional Requirements

- The system should be easy to use.
- The system should provide information quickly.
- The interface should be responsive.
- The system should work on commonly used web browsers.

### Technology

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js / Express
- Version Control: Git and GitHub
