# EnviroMonitor – Requirements Specification
## Version 2.0

### Project Overview
EnviroMonitor is a web-based environmental monitoring system that provides AQI information and helps users understand current air quality conditions.

### Changes from Version 1.0

- Added AQI alert functionality.
- Added administrator-related features.
- Improved location-based AQI information.
- Improved user interaction and interface.

### Functional Requirements

1. The system shall allow users to view current AQI information.
2. The system shall display major air quality parameters.
3. The system shall allow users to search for a location.
4. The system shall display the AQI status of the selected location.
5. The system shall provide alerts when AQI reaches an unhealthy level.
6. The administrator shall be able to manage environmental information.
7. The system shall provide a user-friendly dashboard.

### Non-Functional Requirements

- The system should provide fast responses.
- The system should be reliable.
- The system should be responsive on different screen sizes.
- The system should maintain readable and understandable information.
- The system should provide secure access to administrative features.

### Technology

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js / Express
- Database/API: As applicable
- Version Control: Git and GitHub
